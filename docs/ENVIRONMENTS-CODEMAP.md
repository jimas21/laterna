# Environments: code map

Facts gathered from the code on 2026-11-09 for the environments feature (`docs/ENVIRONMENTS.md`): six areas, each read by one agent and checked by a second; only confirmed or corrected claims, plus the checkers' additions. Paths are repo-relative, `path:line`. *Inference* marks reasoning not read in the repo.

## 1 Rendering today

**Eye targets.** `EyeTarget` is a `Copy` of borrowed handles `{image, view, extent, final_layout}` (`crates/fp-render/src/renderer.rs:39-46`). Built in two places: fp-xr `begin_frame`, from the acquired swapchain image, COLOR_ATTACHMENT_OPTIMAL (`crates/fp-xr/src/session.rs:378-383`); and `OffscreenEyes` (`crates/fp-render/src/capture.rs:16-48`): two colour `Image`s `COLOR_ATTACHMENT|TRANSFER_SRC` plus a readback buffer, TRANSFER_SRC_OPTIMAL.

**Per-eye pass** (renderer.rs:1159-1248): barrier UNDEFINED→COLOR_ATTACHMENT, src `mem::TOP` (1160-1169); one colour attachment, CLEAR to `video.background` (1170-1177); `cmd_begin_rendering` with colour only, **no depth** (1184-1190); `scene_pipe` + slot `scene_set`, 4-byte eye push, `cmd_draw(3)` (1203-1204) — the full-screen triangle, `pos.z = 0.0` (`crates/fp-render/shaders/scene.wgsl:74-81`); then the blended quad pipe in the same instance with a 64-byte push `vp = proj * view` (1221-1247); transition to `final_layout`. The forward VP exists in `draw` (:1223); the scene UBO gets only its inverse (1103-1106).

**Pipelines, shaders.** `pipeline::create(PipelineDesc{spv, layout, color_format, vertex_stride, attributes, blend})` (`crates/fp-render/src/pipeline.rs:7-93`) is the only builder: cull NONE, **no depth-stencil state**, colour format only (68-70); `set_layout` stages VERTEX|FRAGMENT (:106). `crates/fp-render/build.rs:7` compiles `["scene","quad","egui","q10c"]` via naga 28 to SPIR-V 1.3; consts at `crates/fp-render/src/lib.rs:57-60`; push constants are `var<immediate>`. `Drop` destroys a fixed list (renderer.rs:1632-1637); scene pipe `blend: false` (:249).

**Descriptors, uniform, slots.** Scene set 0 UBO, 1 SAMPLER, 2-4 SAMPLED_IMAGE (230-239); tex set sampler + image (252-258). Pool: UNIFORM 16, SAMPLER 1024, SAMPLED_IMAGE 2048, **no STORAGE types** (193-215); sampler CLAMP_TO_EDGE (222-224). `SceneParams` (`crates/fp-render/src/params.rs:14-37`) mirrors `Params` (scene.wgsl:8-55), `size_of` at renderer.rs:440/1139; `params::build` (params.rs:136-254) runs at renderer.rs:1108-1109 with the `FrameDesc` only the renderer has. `bg_color = video.background` (:243); `extra.w` (bg alpha) is never read; `display = [turns,0,0,0]` (:252) has free slots. `SLOTS = 2` (:24); each `Slot` has cmd, fence, uniform, set, buffers and `garbage`/`garbage_sets`/`garbage_buffers` (129-148); `begin_frame` waits the fence and drains garbage (633-666); `one_shot()` (:509) blocks.

**Video upload, Q10C.** `set_video` (682-711): a resident frame skips upload (682-685); else `VideoPlanes::upload` into `videos[1 - video_cur]` on the slot cmd; `recreated` (:699) only on reallocation. Planes (`crates/fp-render/src/video.rs:25-33`): I420 R8/R16 ×3, NV12 [R8, R8G8], P010 [R16, R16G16]; left SHADER_READ_ONLY_OPTIMAL. Q10C is Turnip-only (`crates/fp-render/src/gpu.rs:106`): a descriptor-buffer compute converter (`q10c.rs:489-500`) writes R16/R16G16 `SAMPLED|STORAGE` images (video.rs:365-371), same layout; not a portable template.

**mem.rs, static textures.** `Image::new(gpu, w, h, view_formats, usage, mips, name)` (`crates/fp-render/src/mem.rs:101-109`) makes a view per format; `range()` hard-codes COLOR (219-227). `barrier()` is image-only (231-257); stage consts TOP, TRANSFER, fragment `SHADER_READ`, COLOR_WRITE only (259-276). `create_panel` (renderer.rs:546-610): mipped `[UNORM, SRGB]` Image, `tex_set(views[1])`; `generate_mips` (1521-1588) expects level 0 in COLOR_ATTACHMENT_OPTIMAL; `upload_rgba(&self, dst, w, h, rgba)` (1384-1442) = staging + `one_shot`; `destroy_panel` defers via garbage (620-630).

**Scene shader** (scene.wgsl:300-402). `fs_main` returns one `@location(0)`, no `frag_depth`. Ray: `inv_view_proj[eye] * (ndc, 0/1, 1)` (301-305). `if screen.w < 0.5 return bg_color` (307-309, no frame). `kind == 0` → `flat_uv` (:313); else `anchor_inv` → per-eye rot → `correction` → `off_centre` → `zoom` (315-326) → `equirect_uv`/`fisheye_uv`/`eac_uv`. Miss = `INVALID (-1,-1)`; `if uv.x < 0.0 return bg_color` (338-340). Then YUV, chroma key (348-355), alpha mask (361-366); final blend **in-shader**, premultiplied over `bg_color`: `col*alpha + bg.rgb*(1-alpha), alpha + bg.a*(1-alpha)` (:401).

**Flat screen.** `screen = (w, h, arc, has-video)`, `screen_inv` world→screen-local (scene.wgsl:16-31). Size (params.rs:175-199): per-eye picture aspect, longer side = `screen_width`; `arc = curvature.clamp(0,1)·TAU/3` (:200). `flat_uv` (195-226): plane `t = -o.z/dir.z`, `p = o + t·dir` (203-205); cylinder when `arc > 1e-3`, `r = w/arc` centred `(0,0,r)` (:217); returns uv only. Pose each frame: `screen_pose = place(picture_anchor(anchor), 0, screen_distance, 0, 0)` (`crates/frameplayerx/src/app/frame.rs:583`); `place() = anchor·rot_y(yaw)·translate(0, y, -distance)·rot_x(-tilt)` (`crates/frameplayerx/src/world.rs:264-269`); no scale, so screen-local `t` = world `t`. Anchor (frame.rs:207-236): yaw-only first, yaw+pitch on recentre; Follow (216-220) flat-only; spherical re-anchors each frame (229-234). Defaults 4 m / 5.81 m (72 degrees, Medium) / 0 (`crates/fp-core/src/view.rs`).

**Equirect.** `equirect_uv(d, h_fov, v_fov)` (scene.wgsl:124-136): `lon = atan2(d.x, -d.z)`, `lat = asin(d.y)`, `u = 0.5 + lon/h_fov`, `v = 0.5 - lat/v_fov`; `u` wraps only when `h_fov ≈ 2π`. Forward −Z, up +Y; a sky calls with `(2π, π)`.

**Passthrough, panels.** `passthrough = available && ((settings.passthrough && flat_or_none) || keyed)` → `background = [0;4]` (frame.rs:573-577) → `session.set_passthrough` (`crates/frameplayerx/src/main.rs:572`) → ALPHA_BLEND/OPAQUE (session.rs:222-226). With `supports_quad_layers()` (main.rs:476) shown panels and pointer rays are compositor quad layers (frame.rs:641-653; main.rs:530-567), over the eye image regardless of depth; the eye-pass quad pipe draws only fading panels, subtitles (frame.rs:613-624, 652) and everything in preview/tests.

## 2 OpenXR and the harnesses

**Swapchains, blend.** `Eye { swapchain, images, views }`, no depth (`crates/fp-xr/src/session.rs:25-29`); two colour-only swapchains, first offered of `[R8G8B8A8_SRGB, B8G8R8A8_SRGB]` (:96), COLOR_ATTACHMENT|SAMPLED, 1 sample (:148). No `XR_KHR_composition_layer_depth` anywhere (grep 0; extensions `crates/fp-xr/src/context.rs:37-53`); `openxr = 0.22.0` (`Cargo.toml:46`), depth-layer API unverified. Blend mode defaults to the first listed (175-179); `set_passthrough` flips OPAQUE/ALPHA_BLEND per frame (222-228); `BLEND_TEXTURE_SOURCE_ALPHA` only in ALPHA_BLEND (532-546). `passthrough_available = supports_passthrough_blend()` (main.rs:512); the preview forces `true` (preview.rs:93).

**Projection.** `locate_views` in STAGE else LOCAL (116-126); `proj = math::projection(fov, 0.05, 200.0)` (355-371). `crates/fp-render/src/math.rs:42-44`: `m[10] = -far/(far-near)`, `m[14] = -(far·near)/(far-near)`, `m[11] = -1` — depth 0..1, not reversed. Loop (main.rs): `session.begin_frame` → `renderer.begin_frame` → `app.frame` → `renderer.draw` (528-529) → `renderer.end_frame` → `set_passthrough` (:572) → `session.end_frame`.

**Depth layer availability.** Nothing creates a depth image or queries depth formats. `frame-probe` records extensions, view sizes, blend modes, swapchain formats (`crates/frame-probe/src/xr.rs:257-266, 605-611`) and already probes format properties (`crates/frame-probe/src/vk.rs:250-257, 376-399`): add depth and ASTC formats there. No `probe-reports/` is checked in. The launcher forces 2160 px/eye, 90 Hz (`docs/DEVELOPMENT.md:443`).

**Preview** (`crates/frameplayerx/src/preview.rs`): headless GPU, SRGB renderer, `OffscreenEyes` 1024 px (832-836; `tools/ui-preview.sh:565` uses 1400); head fixed at (0, 1.6, 0) (72-74), `Fov::symmetric(100)`, 0.05/200 (104-110); `layers: false`; `save()` forces alpha 255 (140-166). Commands (table 7-37): `shot`, `sbs`, `panel`, `point`, `click`, `look YAW PITCH`, `screen settings TAB` (255-292), `adjust N`; unknown aborts. Template: `chroma-global` sets a field, `repaint_all()`, `run_frames(3)` (466-470). `ui-preview.sh`: `sbs player-scene` at :429.

**Monado** (`tools/local-xr.sh:158-168`): `XR_RUNTIME_JSON=/usr/share/openxr/1/openxr_monado.json`, `QWERTY_ENABLE=1`, or `XRT_COMPOSITOR_NULL=1` (`tools/local-xr.sh headless --exit-after 10`); same `XrSession` code; controllers `khr/simple_controller`: aim, select, menu (`crates/fp-xr/src/input.rs:145-154`). The preview never touches session.rs.

**GPU tests.** `crates/fp-render/tests/scene.rs:13-23`: `Gpu::headless()` or skip, SRGB, 128-px eyes, far **100** (40-46); `flat_screen_sits_in_front_and_background_surrounds_it` asserts `[0,0,0]` corners (356-380). CI: `cargo test --workspace` with `VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json` (`.github/workflows/ci.yml:204-208`).

## 3 Settings, actions and UI

`Settings` (`crates/frameplayerx/src/settings.rs:54-127`): `#[serde(default)]`, no `deny_unknown_fields`, hand-written `Default` (190-236), atomic save (298-306), `load` migrates by sniffing raw JSON (266-295). Patterns: `source_pins: BTreeMap` with `skip_serializing_if` (125-126); `SubtitleMode` snake_case enum, `#[default]` (36-46); `passthrough: bool` (:71); test `round_trip_and_partial_files` (:314).

**Action flow.** Panels get `View { settings: &mut Settings, actions: &mut Vec<Action>, .. }` (`crates/frameplayerx/src/ui/mod.rs:970-980`); switches mutate `v.settings`, side effects push an `Action` (`TogglePassthrough` ui/mod.rs:397). `paint_panels` → `App::apply` → `sync_settings` (`app/frame.rs:533-536`; `app/actions.rs:302`); `sync_settings` (`app/mod.rs:435-477`) saves whenever `settings != saved`. Panels repaint on 1000 ms timers, each with its own egui `Context` (app/mod.rs:260-271). `FrameOutput { video, passthrough, .. }` (app/mod.rs:78-90) → `set_video` (main.rs:523), `draw` (:529), `set_passthrough` (:572); `App::video` is frame.rs:540-599.

**Passthrough today** is toggled at the armchair key, flat only (`ui/player.rs:653-660`), the library bar (`ui/library.rs:274-280`), a controller command with `toast-room-*` strings (`app/input.rs:109-132`) and the Settings › Passthrough switch, greyed when unavailable (`ui/settings.rs:582-600`).

**Tabs.** Settings tabs: fixed 10-element array (`ui/settings.rs:11`, match 102-113), `SettingsTab` (ui/mod.rs:430-442), no Display tab; Video position ends with Background (481-482). Adjust `tabs()` is a 7-tuple (`ui/player.rs:1085`); haptics sliced off (:1115), footer rule `<= 4` (:1124), `5 => chapters_tab` (:1158); Screen rows 1382-1410, Background 1413. Anything edited through `pb.settings` is per-video `ViewSettings`, Save-gated (1161-1167), saved by `library.set_view_settings` (`playback.rs:1012`); `ViewSettings` is `Copy` (`crates/fp-core/src/view.rs:10`). Pause state: no `is_paused`; use `p.player.state()` (playback.rs:882).

**i18n, widgets, images.** `tr!` (`i18n.rs:52-59`) wraps `i18n_embed_fl::fl!`, compile-checked against `crates/frameplayerx/i18n/en/frameplayerx.ftl`; the test at i18n.rs:283 covers five translations; `# Short: a chip.` marks chips (ftl:118-127). `ui/widgets.rs`: chip 517, key 441, key_face 370, rows 713, segmented 1312; `ui/page.rs`: `picture` 641, `Card` 688, `carousel` 945. `Thumbs` (`ui/thumbs.rs:44`) is keyed by path/URL, so bundled images do not fit it; `controller_map::picture` (`ui/controller_map.rs:97-118`) = `include_bytes!` + `image::load_from_memory` + `ctx.load_texture` cached in `ctx.data`. `icons_have_glyphs` scans `theme.rs:325-330`. Library identity at the app layer: `OpenRequest::source_id` (`playback.rs:24-26`).

## 4 Plex and the play flow

`crates/fp-sources/src/plex/catalog.rs`: `libraries()` → `CatalogItem { kind: Library, id: "section:<key>", collection_type: movies|tvshows|homevideos }` (39-51); `catalog_item` maps Plex `type` (61-73); location `plex://source/<source-id>/<machine-id>/item/<ratingKey>[?media=]` (`plex/mod.rs:391-408`), no section. **`librarySectionID` is read nowhere** (grep 0); whether PMS returns it per item must be confirmed live. `home()` = libraries + `/hubs/continueWatching/items` (20) + 12 latest per library, N+1 (436-468). Direct play via `/video/:/transcode/universal/decision?directPlay=1` (`plex/playback.rs:183-199`).

**Kind is lost before `open()`.** `to_entry()` reduces `CatalogKind` to Video/Directory (`fp-sources/src/catalog.rs:197-209`); `Entry` (`crates/fp-core/src/source.rs:149`) has no kind/library field; `ui/catalog.rs` `request()` (908-921, private) builds `OpenRequest { location, source_id, entry, start_at }`; `Go::Play` (751-758) drops the grid's `CatalogQuery`; `item_row` (:1035) is private. But `playback::open` calls `src.details(e)` on **every** path (`crates/frameplayerx/src/playback.rs:183-203`), Home/history rows included, so plex `entry_details` (`plex/playback.rs:39-58`, which has `raw`) is the single choke point for kind and section.

**Per-video persistence.** `open()` upserts a media row (232-238) and loads `record.view_settings.unwrap_or_else(|| settings.new_video_view())` (518-521); save 1011-1017, `save_key` 1036 (immediate). `Library::set_view_settings` (`crates/fp-library/src/library.rs:1026`), `set_tracks` (:1038). Per-video settings are `media` columns; migrations appended at `crates/fp-library/src/schema.rs:114-118`; `MediaRecord` `record.rs:141`, positional `media_from_row` :397, tags subquery at index 31. A picked version appends `?media=` (plex/playback.rs:53-55): dedupe by `/item/<ratingKey>`. `VideoParams` (params.rs:42-61) already carries `settings: ViewSettings`.

**Home.** `Screen::Home` is local-DB only (`ui/library.rs:480-505`; rows open with `entry: None`, 327-338). The Plex home loads only when a source is opened from Sources (`app/sources.rs:203-211`); `Job::Catalog` is routed **by source** to an open `CatalogView` (`app/tasks.rs:386-388`), else dropped. `PlexConfig` (`fp-sources/src/config.rs:254-279`) is per-source, serde-default. ## 5 Build, packaging and assets

Linux or WSL2 only; no Windows build (`docs/DEVELOPMENT.md:8`); keep `CARGO_TARGET_DIR` off `/mnt`. `rust-toolchain.toml:5-7` pins 1.99.1 + `aarch64-unknown-linux-gnu`; zig and cargo-zigbuild come from `tools/requirements.txt`.

```
# once, WSL2, repo root
python3 -m venv ~/.local/frameplayerx-tools && ~/.local/frameplayerx-tools/bin/pip install -r tools/requirements.txt
export PATH=~/.local/frameplayerx-tools/bin:$PATH && rustup toolchain install && tools/build-ffmpeg.sh aarch64
cargo build --release -p frameplayerx-install && target/release/frameplayerx-install pair <headset-ip>   # headset: Steam Settings > Developer > Pair new host
# each build  (build-frame.sh:15 = cargo zigbuild --release --target aarch64-unknown-linux-gnu.2.28)
tools/build-frame.sh -p frameplayerx && tools/package.sh
target/release/frameplayerx-install --zip dist/frameplayerx-0.0.0-dev-aarch64.zip --reinstall [--restart-steam]
ssh frame tail -f .local/share/frameplayerx/frameplayerx.log
# binary-only swap while lib/ is unchanged (pattern: tools/frame-probe.sh:24-25)
scp target/aarch64-unknown-linux-gnu/release/frameplayerx frame:frameplayerx/frameplayerx
```

`--reinstall` is needed: every local build is `0.0.0-dev` and the installer skips copying when VERSION matches (`crates/frameplayerx-install/src/ops.rs:268`).

**package.sh** (`tools/package.sh`) stages one root `frameplayerx/`: binary, `frameplayerx.sh`, `lib/` (five FFmpeg .so), `licenses/`, `assets/steam/*.png`, README/LICENSE/NOTICE, `VERSION` (42-52); fails on a crate with no licence file not in `packaging/licenses/rust-crates-extra.txt` (90-94); checks aarch64, max `GLIBC_` ≤ 2.28, `$ORIGIN/lib` RPATH (102-107; set in `crates/frameplayerx/build.rs:7-10`). Headset layout `~/frameplayerx` + `.old`/`.new` (`crates/fp-updater/src/install.rs:7-9`); `inspect_zip` requires only `frameplayerx` and `VERSION` (169-186); symlinks rejected (101-108). The manifest hashes the whole zip (`manifest.rs:64-73`): new files need no manifest change. Only `current_install_dir()` (`fp-updater/src/lib.rs:126-131`) looks beside the binary; `fp_core::dirs` has config/data/cache only (`crates/fp-core/src/dirs.rs:18-36`).

**Assets are all embedded**: fonts (`ui/theme.rs:81`), controller PNGs, Fluent via rust-embed (`i18n.rs:15`), SPIR-V. `image 0.25` is a dependency of `frameplayerx` only (Cargo.toml:36), not a workspace dep (`Cargo.toml:25-35`); the lock has glam 0.33.12, image 0.25.10, png 0.18.1 and **no gltf, ktx2, basis or astc**. Release profile `lto = thin, strip = debuginfo` (Cargo.toml:58-61); `include_bytes!` inflates every updater download. `packaging/licenses/THIRD-PARTY.txt:27-31` lists embedded fonts; `packaging/README.txt:7-13` lists shipped files.

**CI** (`.github/workflows/ci.yml`): version job ignores only `*.md`, `docs/`, `site/` (:74); shellcheck on `tools/*.sh` (:174); `check` (192-228) runs fmt, clippy, docs, lavapipe tests, ui-preview, `package.sh` (:223); an `installer` matrix job (231+); `release` (274) needs all three, signs with `FP_RELEASE_KEY`.

## 7 Risks and open questions

- **design impact** (renderer-gpu, xr-preview): ENVIRONMENTS.md:20 puts depth on the eye *target*, but EyeTarget is built in fp-xr and capture.rs and the XR swapchain cannot supply depth; a Renderer-owned per-extent cache keeps both untouched. Decide before milestone 2.
- **design impact** (xr-preview, settings-ui): passthrough is a compositor blend mode and `keyed` video forces it on (frame.rs:568-577); rooms must force OPAQUE, `passthrough` must be the only id keeping that branch, and the `Settings::passthrough` bool with its three toggle sites must migrate into the enum.
- **design impact** (scene-shader): 180°/360° video also returns `bg_color` past the picture edge — gate the env pass on `projection == Flat`. In-shader blending (:401) shows the bg colour, not the room, behind chroma-keyed pixels unless the scene pipe blends or discards.
- **design impact** (scene-shader): the screen rectangle depends on `FrameDesc`, known only inside `Renderer`; the area light must be computed in `draw` (factor params.rs:175-200) and is off before the first frame.
- **design impact** (plex-playflow): per-library defaults cannot be derived at the app layer today and `librarySectionID` is unverified; key by `collection_type`. Per-video memory needs a schema change.
- (renderer-gpu) Every pipeline in the eye instance must declare the depth format (*inference*); the preview hits the quad-pipe mismatch first. In XR, panels and pointer rays are compositor layers, so a room never occludes the pointer.
- (renderer-gpu) `SceneParams`/`Params` must stay byte-identical (`size_of` at renderer.rs:440/1139); `frag_depth` disables early-Z, so the env pass runs first. No STORAGE pool types, no COMPUTE stage, image-only barriers; per-frame buffers need one copy per slot.
- (xr-preview) Standard depth, near 0.05 / far 200 (tests 100): D16 risks z-fighting, D32_SFLOAT is safer; reversed-Z would change `math::projection` (*inference*). No probe report exists. Monado controllers are aim + trigger + menu only. Open: also a compositor depth layer?
- (scene-shader) Follow mode and spherical re-anchoring move `screen_pose` every frame; a world-pinned room drifts. Open: does a sky follow `anchor_inv`?
- (settings-ui) Adjust-tab dispatch is positional; a live house-lights slider writes the settings file per drag frame (debounce); thumbnails do not fit `Thumbs`; renaming `settings-video-position` touches five translations.
- (plex-playflow) `media_from_row` is positional; a Plex-first Home needs `request`/`item_row` made `pub(crate)`, a new branch at `tasks.rs:386` and dedupe by ratingKey. Open: save a per-video env immediately or with Save; map in `settings.json` or `PlexConfig`.
- (build-packaging) Native KTX2/ASTC must cross-compile through zig (glibc 2.28); Turnip ASTC support is unverified; `extract_zip` rejects symlinks (`cp -L`); shipped `assets/` needs a dev fallback; `env.wgsl` must pass naga at SPIR-V 1.3. Open: embed vs `assets/env/`.
